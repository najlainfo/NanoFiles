# NanoFiles (Proyecto Java)

**Descripción del Proyecto**
Sistema *peer-to-peer* (P2P) para el intercambio de archivos en red. Desarrollado en Java, este proyecto implementa conectividad mediante sockets UDP y protocolos de comunicación a medida para optimizar la transferencia de datos.

**Tecnologías Utilizadas**
* Java
* Sockets (UDP)
* Arquitectura P2P

**Objetivo**
Comprender y gestionar el tráfico de red y la transferencia eficiente de paquetes de datos a bajo nivel.
